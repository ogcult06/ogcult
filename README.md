# OG CULT Black Label

Create a premium dark luxury streetwear website for my clothing brand OG CULT. Use a black background, oversized typography, cinematic product photography, subtle grain, smooth scroll animations, editorial fashion layouts, and minimal navigation. Create Home, Shop, Product, About, Contact and Cart pages. Make the website mobile-first. Integrate Shopify so products, inventory, cart and checkout are handled by Shopify. The design should feel expensive, rebellious, underground and modern—not like a generic Shopify template.
